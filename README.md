# SyncEhr releases

Signed, notarised and stapled builds of **SyncEhr**: right-click media in Finder and choose **Send to Arena > Layer > Column** to load it into Resolume Arena's clip grid.

- Download: [Releases](https://github.com/AmritusG/syncehr-releases/releases) (`SyncEhr-<version>.dmg`, SHA-256 in the release notes and in `SyncEhr-<version>.dmg.sha256`).
- Source code, install guide and licence (GPL-3.0-or-later): [AmritusG/syncehr-public](https://github.com/AmritusG/syncehr-public).

Requires a Mac with Apple silicon, macOS 14 or later, and Resolume Arena with its webserver turned on.
