# SendEhr releases

Signed, notarised and stapled builds of **SendEhr** (formerly SyncEhr): right-click media in Finder and choose **Send to Arena > Layer > Column** to load it into Resolume Arena's clip grid.

- Download: [Releases](https://github.com/AmritusG/sendehr-releases/releases) (`SendEhr-<version>.dmg`, SHA-256 in the release notes and in `SendEhr-<version>.dmg.sha256`).
- Source code, install guide and licence (GPL-3.0-or-later): [AmritusG/sendehr-public](https://github.com/AmritusG/sendehr-public).

Requires a Mac with Apple silicon, macOS 14 or later, and Resolume Arena with its webserver turned on.
